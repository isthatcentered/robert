Use the `robert` cli to manage a local library of repositories. 

Run `robert --help` for commands.

You are free to add repositories whenever they help answer a question. 

Match the dependency version in the project's manifest (such as package.json); Add the repository with Robert at the matching tag or commit, then explore the returned local path. Read implementation, tests, and examples; answer with relevant file references.
