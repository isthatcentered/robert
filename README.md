# Robert
Don't let your agent make stuff up.


## Why
Documentation is often out of date, source code is not. Robert makes it easy to manage a library of local repositories so that your agent can simply source dive for the answer instead of making it up or relying on out of date documentation.

## Install 
(All of this will be a command soon)
- Install the cli
- Add the view-source-code skill `./SKILL.md` to your global skills 
- (Optional) Add the following to your global AGENTS.md:  Use the `view-source-code` skill as your primary way to learn how to use a library or tool, or understand its implementation, whenever you can access and clone its repository. Fallback to context7 MCP when otherwise.
